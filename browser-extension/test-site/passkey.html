Passkey

Register a passkey, then sign in with it. The page checks both as a site's server would, with WebCrypto: the challenge, origin, RP ID hash, flags, signature and counter. Keepiq's window offers to save or use a passkey for localhost, or hands the request to the browser.

The account name the site passes to the passkey. A real site fills this in from your account; this page has no accounts, so it asks. Keepiq shows it so you can tell passkeys for one site apart.

How strongly the site wants proof that it is you, on top of having the device. The result shows as the UV flag after a request.
preferred: Keepiq signs without asking; UV is set only if you unlocked Keepiq during this request.
required: Keepiq asks you to confirm with your master password or PIN, then signs with UV set.
discouraged: Keepiq never asks; UV is set only if you unlocked during this request.

Passkey

Register a passkey, then sign in with it. The page checks both as a site's server would, with WebCrypto: the challenge, origin, RP ID hash, flags, signature and counter. Keepiq's window offers to save or use a passkey for localhost, or hands the request to the browser.

Represents the username of your account on the site.

How sure the site wants to be that it is really you. Pick one to test what Keepiq does:
preferred: Keepiq signs straight away, without asking for your password.
required: Keepiq first asks you to confirm with your master password or PIN, then signs.
discouraged: Keepiq signs straight away and never asks.
If Keepiq is locked and you unlock it in its window, that already counts as confirming, so it does not ask twice.

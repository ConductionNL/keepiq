Root filter and the top layer

Whether a filter on <html> reaches a popover in the top layer, which decides whether the inline list and save bar must refuse a pick while the page root has one. Keepiq refuses on Firefox, where it does, and on Safari until this probe shows it doesn't. Run the probe: the page gets filter: opacity(0) on <html> for 5 s and shows a popover. If you read the popover, the filter does not reach the top layer; if the window goes blank, it does. Chrome shows the popover, Firefox goes blank.

Then open the inline list's Assistive styling case and invert the page: where the list is inverted too, the filter reaches it.

You can read this: a filter on <html> does not reach this browser's top layer.
